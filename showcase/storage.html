Why the gap exists

Store the instructions,
not every result.

A loop can describe hundreds of feathers in a few lines. A curve and a radius can describe a trunk. An SVG drawing or a paint function can describe a patterned coat. The code stores the recipe and its parameters.

The finished GLB stores the generated geometry, UV coordinates, skin weights and skeleton, plus embedded rasterised textures. Repetition becomes actual vertices and pixels.

The work moves, it does not disappear. Loading a small recipe means the visitor’s browser must construct the model and generate its textures. A GLB needs decoding and rendering, but avoids rerunning those construction algorithms. Smaller storage does not mean lower runtime memory or faster loading.

What this comparison counts.

One source, one final export

All direct samples/*.ts files are measured by their byte length, including comments, formatting, inline SVGs and paint functions. Each is paired with its latest available B/out/<slug>-rigged.glb, or A/out/<slug>.glb for a plain model. Mesh-only duplicates, historical renders and experiment builds are not added together.

An existing-export snapshot

The website build measures current source files and existing exports; it does not regenerate every model. Export and source versions may differ. Both file timestamps are recorded in the CSV. Models without a final export are excluded from totals and listed separately.

The arithmetic

Saved bytes = GLB bytes − source bytes. Reduction = saved bytes ÷ GLB bytes × 100. The library’s reduction is calculated from summed bytes, not the average of model percentages. “GLB / code” is the GLB size divided by the source size.

What is outside the numbers

Shared SDK, style kits, three.js and viewer code are not included in each model’s source size. This is not a measurement of network transfer, minified or gzip/Brotli-compressed JavaScript, or Draco/Meshopt-compressed GLBs. GLB sizes are measured from local exports; the published site generates models from code and does not host the binaries. This comparison is not a measured bandwidth or bill reduction.
