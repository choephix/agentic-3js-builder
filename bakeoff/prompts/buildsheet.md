## Build sheet

The module opens with its build sheet: one `/* … */` block comment of at most 40 lines, before the imports, in plain words and numbers:

- **Proportions:** the overall length, width and height in meters, and the main masses with their sizes.
- **Parts:** the part list, each part with its size.
- **Palette:** the colours as hex values, each with where it goes.
- **Signature features:** the few that make the subject read as itself, and how each is built.

The code below the sheet builds what it lists. The sheet lives inside the module, so the reply stays one ```ts block that runs as it is.
